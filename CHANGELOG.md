# Changelog

## 0.1.0 — 2026-10-26

- Native Swift Mac app with a bundled native messaging client; no Python runtime needed.
- Universal macOS 14+ package for Apple Silicon and Intel.
- Wizard-hat app/menu icons with a large J badge, three UI languages and a 1024-wide history sheet.
- Turn-controlled local agent conversations, pause/resume, search and actions reports.
- Chinese/English documentation and project pages with download links.
- Removed legacy Python server/client, obsolete fedora artwork and generated icon intermediates.

Known limits: signing/notarization status is stated per release; Intel binary is cross-built but not run on Intel hardware; full real-agent multi-round visual acceptance remains incomplete. Messages are kept only in memory.
